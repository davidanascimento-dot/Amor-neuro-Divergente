# Leitura neuroacessível — o que entrou no site

Copie estes arquivos para a raiz do projeto (mantendo as pastas) e rode `npm run build`.

Novos: `leitura-neuro.css`, `leitura-neuro.js`, `fonts/OpenDyslexic-*.woff` (licença SIL OFL)
Alterados (só 2 linhas cada: um <link> e um <script>): `blog/artigo.html`, `blog/post-masking.html`, `blog/post-procrastinacao.html`

Para ativar em outra página de leitura, basta incluir:
  <link rel="stylesheet" href="/leitura-neuro.css">
  <script src="/leitura-neuro.js"></script>
